# Communication Guidelines

- Always begin every response with a full-width horizontal divider line using Unicode box-drawing characters (at least 80 to 100 characters: `────────────────────────────────────────────────────────────────────────────────────────────────────`) followed by a blank line before starting any text or explanation. The line must span across the full width of the interface without collapsing into a short Markdown HR widget.
